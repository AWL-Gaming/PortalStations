# Portal Stations
Remake of Lunatix42 Portal Stations.

Adds Portal Stations and a Personal Teleportation Device which allow users to fast travel between locations.

Complete overhaul of logic while maintaining the original style and UI.

Original plugin: https://www.nexusmods.com/valheim/mods/2024

## Configurations
Improved and updated configurations.
- Teleport Anything
- Portable Device Fuel
- Portable Device Fuel Amount
- Portable Device Upgrade Benefit
- Server Synced
- Build Cost
- Teleport keys to enable unteleportable items to be enabled via global keys

### AWL 1.4.7 compatibility work

- Updated the mod for current Valheim 1.0 APIs.
- Added current `Hoverable.GetHoverOffset()` compatibility.
- Updated teleportability calls for the current Valheim signature.
- Updated embedded PieceManager handling for current `PieceTable` category storage.
- Fixed the bundled ServerSync broadcast path after `ZRoutedRpc.Everybody` became a constant in current Valheim.
- Updated project references and packaging so the fork builds against current Valheim development assemblies.
